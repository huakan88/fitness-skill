# Ep.01 口播结构大纲（池 #1）

完整定稿见源稿：`content-team/drafts/2026-11-01-fitness-ep01-daodao-v2.md`（侃华已过眼）。

- **题名**：看起来瘦，一提重物却没劲？
- **比喻**：肌肉是引擎，肌腱和髋是传动绳；久坐 → 髋屈肌缩、臀大肌懒 → 提物发力链打滑。
- **Hook**：瘦上班族提桶装水发虚 → 不在「太瘦」而在发力开关关掉 → 椅边拨回来。
- **动作三步**（组数+避坑）：
  1. 椅边开髋 · 左右各 25s×2 · 避坑：别塌腰撅臀
  2. 坐姿夹臀等长 · 顶住 10s×8 · 避坑：别憋气挺腹
  3. 椅边起立 · 10次×2 · 避坑：膝内扣 / 弓背甩腰
- **做错一条**：全程用腰代偿（开髋塌腰、夹臀挺腹、起立弓背）。
- **CTA 打卡**：「臀到了」/「还是腰」。
- **成片**：follow-clean 全片 · 约 116s · 刘飞 · 见 `references/ep01-delivery-notes.md`。
