# Ep.02 口播结构大纲 · 口语 v2（池 #2）

完整定稿见源稿：`content-team/drafts/2026-11-01-fitness-ep02-belly-arch-script.md`（口语人话版 · 已配音成片）。

- **题名**：不胖，小腹为什么先往前拱？
- **比喻**：胯骨是底座，肚子前面是帆布；坐久底座松/前倒、肋骨上翻 → 帆布松 → 小腹先显（不全是突然长肉）。
- **Hook**：秤没涨多少、站直小肚子先拱 → 不是突然胖 → 床上两步收「帆」。
- **动作两步**（组数+避坑）：
  1. 死虫式 · 左右交替 8次×2 · 避坑：腰别拱桥；慢比高重要
  2. 坐姿收肋+轻夹臀 · 顶住 8s×6 · 避坑：别憋气挺肚子
- **做错一条**：用腰硬撑 / 憋气把肚子顶出去。
- **CTA 打卡**：「肋骨沉」/「还是挺」。
